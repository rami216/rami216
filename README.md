<h2 align="center">🤖 Zygoflow — AI Agent Factory</h2>
<h4 align="center"><a href="https://zygoflow.com/agents">zygoflow.com/agents</a> · Desktop app available on request</h4>

<h3>🧩 Agent Architecture</h3>

| Feature | Description |
|---|---|
| **Sub-Agents** | Each agent is composed of sub-agents, each handling one atomic step |
| **Code Generation** | Each sub-agent generates executable Python code from a natural language prompt |
| **Skills System** | Sub-agents can be enhanced with Skills — reusable blueprints that teach the AI how to perform specific tasks |
| **X-Mode** | Automatic skill selection using RAG (vector embeddings) — picks the most semantically relevant skills for each sub-agent |
| **Manual Skill** | Users can manually assign a specific skill to any sub-agent |
| **Code Editor** | Built-in inline code editor — view, edit and re-run generated code per sub-agent |

<h3>🔗 Pipeline & Orchestration</h3>

| Feature | Description |
|---|---|
| **Pipeline Orchestrator** | Chain multiple agents into sequential pipelines with shared memory |
| **Auto-Run Mode** | Pipelines run autonomously until `is_done = True` — ideal for fully automated workflows |
| **Dynamic Routing** | Agents can route to any other agent in the pipeline using `next_agent` |
| **Multi-Round** | Pipelines can run for N rounds or loop indefinitely in auto mode |

<h3>⏰ Triggers & Automation</h3>

| Feature | Description |
|---|---|
| **Scheduled Triggers** | Run pipelines automatically at fixed intervals (every X minutes/hours) |
| **Daily Triggers** | Schedule pipelines to run at a specific time every day |
| **Folder Watch** | Trigger a pipeline automatically when a new file appears in a folder |
| **Custom Webhooks** | Expose pipelines as HTTP endpoints — trigger from any external service via POST request |
| **ngrok Integration** | Automatically generates a public webhook URL using ngrok |

<h3>🖥️ Execution Environments</h3>

| Feature | Description |
|---|---|
| **Local Execution** | Agents run locally on the desktop via `exec()` with full access to local files and tools |
| **Cloud Execution (E2B)** | Webhook and scheduled triggers execute securely in E2B cloud sandboxes |
| **Export as App** | One-click export of any pipeline as a standalone CustomTkinter desktop app for clients |

<h3>🧠 Brain — Autonomous Planner</h3>

| Feature | Description |
|---|---|
| **Goal Decomposition** | Brain takes a natural language goal and automatically breaks it into subtasks |
| **RAG Skill Matching** | Each subtask is matched to the most relevant skills via vector embeddings |
| **Autonomous Execution** | Brain generates and executes code per subtask without human intervention |
| **Self-Healing** | If a subtask fails, Brain automatically fixes the code and retries up to 3 times |
| **Conversational Memory** | Variables and context persist across multiple Brain runs in the same session |

<h3>🔌 Integrations & APIs</h3>

| Feature | Description |
|---|---|
| **Custom APIs** | Users define their own API integrations — AI auto-generates the function code |
| **Google Workspace** | Built-in Google Sheets, Docs, and Drive integration via service account |
| **Website Connector** | Agents can read and write directly to the user's Zygoflow website database |
| **Third-party Services** | Any API injectable into any agent via the Custom APIs section — built-in examples include SendGrid, Telegram, Stripe, Supabase, and Vercel |
| **Local LLM** | Ollama support for running agents fully offline with local models |
